### 🚀 Selected Engineering Projects

#### 1. [GameVault Backend API](https://github.com/nicholasbenaya/gamestore-be)
*Node.js · Express · Prisma ORM · MySQL/TiDB · Jest & Supertest · Sharp · AWS S3/MinIO*
* **Architecture**: Production-grade REST backend for a digital game distribution platform with distinct User and Publisher tiers.
* **ACID Transactions**: Implemented interactive database transactions preventing race conditions on wallet top-ups and atomic multi-step checkout (discount calculation, wallet debit, library ownership propagation, and wishlist eviction).
* **Automated TDD Pipeline**: Full integration test suite executed with Jest & Supertest before feature merges.
* **Asset Optimization**: Built an in-memory multipart upload pipeline converting images to lossless WebP via native `sharp` before offloading to S3-compatible object storage.

#### 2. [Particle Collision Simulation](https://github.com/nicholasbenaya/collision-simulation)
*C++ · SFML · Spatial Hashing · Performance Benchmarking*
* **The Problem**: Overcame the classic $O(N^2)$ brute-force bottleneck in real-time particle collision detection.
* **Solution**: Engineered a modular collision engine implementing **Spatial Hashing** (`SpatialHashDetector`) alongside continuous cell-size scaling ($2 \times \sqrt{\text{mass}} \times 20$), preserving high frame rates during high-density simulations.

#### 3. [Zero-Config UDP Chat & Custom DNS Service](https://github.com/nicholasbenaya/simple-client-server)
*Python · Raw Sockets · UDP Broadcast Protocols · LAN Discovery*
* **Dynamic Service Discovery**: Built a multi-tenant socket architecture where chat rooms dynamically register with a local DNS authority over `255.255.255.255` UDP broadcasts.
* **Protocol Control**: Handled dynamic live room switching, real-time public/private authorization gates, and graceful socket shutdown without relying on third-party frameworks.

#### 4. [First-Principles Computer Vision Labs](https://github.com/nicholasbenaya/PCV_Tugas)
*Python · NumPy · Matplotlib · Mathematical Image Processing*
* **Mathematical Implementations**: Implemented 2D spatial convolution filters completely from first principles (zero-padding sliding windows, Gaussian kernels, Laplacian, Sobel horizontal/vertical gradient magnitudes).
* **Manual Intensity Modeling**: Built manual CDF-based histogram equalization and non-linear intensity transforms (Gamma correction, logarithmic scaling, contrast stretching) without library shortcuts.

#### 5. [help-umkm — Pro-Bono Digital Infrastructure Monorepo](https://github.com/nicholasbenaya/help-umkm)
*Next.js 14 · React · Tailwind CSS · Embedded Analytics*
* Pro-bono civic-tech monorepo providing zero-cost web infrastructure for Indonesian micro-enterprises.
* Shipped **Nadia Studio** (Florist & MUA in Samarinda): Apple-inspired minimalist UI, embedded analytics engine, WhatsApp lead attribution, and lightweight local storage without recurring database overhead.
